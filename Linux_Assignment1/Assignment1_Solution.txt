1. What is the difference between mkdir and touch?

mkdir : used to create directory. 

touch : used to create empty files. If the file already exists, It updated the file's timestamp without changing its content.

 

2. What is the difference between cp and mv?

cp : used to copy/duplicate the file. 

mv :  used to move/rename a file. It does not duplicate the file.



3. What happens when you use cat > file.txt and the file already exists?

> is used for output redirection. 

If the file already exists, it will overwrite the file.



4. What happens when you use cat >> file.txt and the file already exists?

>> is used to append the output. 

If the file already exists, the output will be appended in the existing content.



5. What does Ctrl+D do when using cat > file.txt?

Ctrl+D helps to come out of the cat command. Basically it signals EOF on the terminal input.



6. What is the difference between cat and tac?

cat :  displays the content of a file i forward order

tac :  displays the content of a file is reverse line order.



7. What is the purpose of head?

head : displays the beginning of a file.  By default it displays the first 10 lines



8. What is the purpose of tail?

tail : displays the end of files. By default it displays the last 10 lines



9. How do you display only the first 5 lines of a file?

head -n 5 file.txt



10. How do you display only the last 5 lines of a file?

tail -n 5 file.txt



11. What happens if you use mv to move a file to another directory?

The file is moved to another directory and is no longer in the original directory.



12. Can cp copy a directory? If yes, what option is generally required?

Yes. cp -r  <directory destination>



13. where do you find system log files? which directory?

/var/log
