Question: Why can free memory be very low while available memory is still high? Answer: Linux uses otherwise idle RAM for caching to improve performance. Therefore, free memory can be low while available memory remains high. When checking whether a Linux system is running out of RAM, the available column is generally more useful than free.

Answer:

What is the PID? Process ID uniquely identifies a process while it exists.
Who owns the process? root — shown in the UID column of ps -ef.
When was the process started? 11:54 — shown in the STIME column. It indicates the start time for this process.
What command started the process? bash — shown in the CMD column. The process is running the Bash shell.
How many threads does it have? 1 — your ps -T -p 1 output shows one thread.
What are the thread IDs? 1 — shown in the SPID column.
What is the difference between a process and a thread?
 Process: A program in execution, with its own process resources and virtual address space.
Thread: A unit of execution within a process. Threads in the same process generally share its memory and other resources, but each has its own execution state and stack.
Relationship: A process can contain one or multiple threads.

Answer:

What is user time? is the CPU time spent executing the program's code in user space. 
What is sys time? is the CPU time spent executing kernel code on behalf of the program, typically while handling system calls
