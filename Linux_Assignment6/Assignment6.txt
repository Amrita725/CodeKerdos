Questions:

What is the difference between hard link and soft link?
Hard link: Another directory entry pointing to the same inode and file data as the original. Both names access the same underlying file.
Soft link (symbolic link): A separate file containing a path to the target. It has its own inode and can become broken if the target is removed or moved.

Why does the hard link still work after deleting the originalâ
A hard link refers directly to the same inode as the original file. Deleting the original filename removes only that directory entry. The file's data remains available as long as another hard link refers to the inode.
Why does the soft link become broken?
A soft link stores the target's pathname rather than directly referring to its inode. When training.txt is deleted, the path no longer resolves to a file, so training_soft.txt becomes a dangling symbolic link.

awk '
{
    total++

    if ($7 == 200)
        successful++
    else if ($7 == 401)
